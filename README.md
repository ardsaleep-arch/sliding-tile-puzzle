# Sliding Tile Puzzle

เกมเรียงตัวเลข 1–15 (15 puzzle) หน้าเดียว ไม่ต้องติดตั้งอะไร เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย

## วิธีเล่น

- คลิกตัวเลขที่อยู่ติดกับช่องว่าง เพื่อเลื่อนเข้าไปในช่องว่าง
- หรือใช้ปุ่มลูกศรบนแป้นพิมพ์
- เรียงตัวเลข 1–15 จากซ้ายไปขวา บนลงล่าง ให้ช่องว่างอยู่มุมขวาล่าง

## คุณสมบัติ

- นับจำนวนครั้งที่เลื่อน และจับเวลา (เริ่มเมื่อเลื่อนครั้งแรก)
- สุ่มกระดานด้วยการเลื่อนย้อนจากกระดานที่เรียงแล้ว จึงรับประกันว่าแก้ได้ทุกครั้ง
- ปุ่ม "เริ่มเกมใหม่" สุ่มกระดานใหม่ ปุ่ม "เรียงใหม่" กลับไปที่กระดานที่เรียงถูกแล้ว
- รองรับหน้าจอมือถือ และมี `aria-label` สำหรับ screen reader

## เทคโนโลยี

HTML, CSS และ JavaScript ล้วน ไม่มี dependency
